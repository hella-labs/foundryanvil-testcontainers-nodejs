# Security Policy

## Supported Versions

Security fixes are provided for the latest published package release. Use the
newest npm release and keep the Node.js and Docker-compatible runtime up to date.

## Reporting a Vulnerability

Please report vulnerabilities privately through GitHub Security Advisories:

https://github.com/hella-labs/foundryanvil-testcontainers-nodejs/security/advisories/new

Do not open a public issue for a vulnerability. Include enough detail to
reproduce the issue, such as the affected version, environment, configuration,
minimal reproduction, and impact.

We will acknowledge a report, assess the impact and affected versions, and
coordinate a fix and release. We may ask for additional information before
publishing a resolution.

## Safe Handling

Do not include credentials, private keys, RPC API keys, or private endpoints in
security reports or public issues. Test credentials should be synthetic and
test networks should not contain real assets.
