# Support

- [Documentation](https://hellalabs.dev/foundryanvil-testcontainers-nodejs/)
  contains task guides and API reference material.
- [Examples](examples/README.md) contain runnable end-to-end workflows.
- [Bug reports](.github/ISSUE_TEMPLATE/bug_report.yml) are for reproducible
  incorrect behavior.
- [Feature requests](.github/ISSUE_TEMPLATE/feature_request.yml) are for new
  behavior or APIs.

Search existing issues before opening a new one. For security reports, follow
[SECURITY.md](SECURITY.md) and use GitHub Security Advisories rather than a
public issue.
